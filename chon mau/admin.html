Dữ liệu lưu vào trình duyệt. Dùng "Xuất JSON" để sao lưu, "Nhập JSON" để khôi phục.

Đồng bộ sản phẩm từ Google Sheet

Gom theo cột mã (SKU): mã giống nhau = 1 sản phẩm, biến thể nằm chung thẻ. Ảnh Drive tự đổi thumbnail; ảnh 1 = mặt trước, ảnh 2 = mặt sau lật được. Món SP mua kèm bạn tự chọn từ kho trong phần sửa sản phẩm (không tự thêm).

Thư mục lưu dữ liệu (tự lưu trực tiếp)

Xuất trylook-data.json, trylook-bgs.json, cau-hinh.json + file ảnh/nhạc tải từ máy tự động vào thư mục đã chọn mỗi khi có thay đổi. Cần Chrome / Edge mới; mở lại trang có thể phải cấp quyền lại — chọn lại cùng thư mục.
Khuyến nghị: chọn chính thư mục chứa 2 file web (thư mục DA4) — ảnh úp lên sẽ thành file ngay tại đó, web đọc được đường dẫn tên-file.jpg.

Nền mẫu trên cửa hàng

Nền hỗ trợ gradient/màu CSS và ảnh URL (hoặc tải từ máy — tự nén). Có ảnh thì CSS tự gọn dạng url(...) center/cover.

Âm lượng 60%

Lưu tự động. Cửa hàng sẽ có nút ♪ bật/tắt nhạc ở góc trái. Chấp nhận link Google Drive: dán link chia sẻ thường, web tự đổi thành link phát trực tiếp — file trên Drive phải bật “ai có link đều xem được”. File tải từ máy chỉ nhận ≤ 2MB.

Menu cửa hàng

Bỏ tick = ẩn danh mục khỏi menu trên web (sản phẩm vẫn còn trong "Tất cả"). Menu lấy phân loại cột D trên sheet.

Dữ liệu lưu vào trình duyệt. Dùng "Xuất JSON" để sao lưu, "Nhập JSON" để khôi phục.

Đồng bộ sản phẩm theo Web chính

Kéo toàn bộ sản phẩm từ source web chính (data/products.json — nơi admin cập nhật từ Google Sheet) vào trang chọn mẫu: gom theo mã chung (SKU), ảnh 1 = mặt trước, ảnh 2 = mặt sau, phân loại (5A → 30A, phích cắm, 1 pha…) giữ theo web. Giá/tên hiển thị trên cửa hàng luôn tự bám theo web chính khi khách mở trang.

Nền mẫu trên cửa hàng

Mặc định là 11 nền từ kho ảnh (bg 0 → bg 10). Có thể đổi tên, thay ảnh (URL hoặc tải từ máy — tự nén), thêm hoặc bớt nền. Có ảnh thì CSS tự gọn dạng url(...) center/cover.
